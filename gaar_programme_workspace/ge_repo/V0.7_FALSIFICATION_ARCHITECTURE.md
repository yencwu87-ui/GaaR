# v0.7 Falsification Architecture

```text
ClaimRegister + GroundingAssessment
              |
              v
       Context Package
   claims / evidence / requirements
              |
              v
       Probe Drafts (bounded)
              |
              v
     Falsification Compiler
      /       |       \
 counterfactual  missing  alternative
      \       |       /
         admissible ProbeRecord
              |
              v
        coverage / execution
```

The compiler, not the model, owns admissibility. A probe is reproducible because it carries the
claim fingerprint, evidence IDs, requirement element ID, context-package ID, source-version hashes,
and model/prompt versions.
