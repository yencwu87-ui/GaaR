# v0.9 Lane A Plugin Platform

This build introduces the shared collection substrate for Lane A first, with Lane B kept as a future adapter over the same observations.

## Added
- `observations.py`: canonical, hashable `Observation` and `EvidencePacket` schemas.
- `events.py`: new append-only `observed` event kind plus `events.observations()` projection.
- `plugins/sdk.py`: minimal plugin contract.
- `plugins/registry.py`: built-in plugin registry.
- `plugins/github.py`: read-only GitHub branch-protection collector.
- `plugin_registry.py`: compatibility facade.
- Assess UI: `Manual / File / Plugin` evidence source selector, plugin collection, provenance display, and `Use this observation as evidence`.
- Plugin observations are recorded globally first; they are only bound into an assessment cycle when the evidence enters the normal Lane A workflow.

## Lineage rule
`observed` means the external system reported a fact. `evidence_bound` means that fact was deliberately included in a governed assessment cycle. The same observation may therefore be reused across cycles without rewriting its original observation record.

## GitHub collector
Set `GITHUB_TOKEN` for authenticated collection. The first built-in target is `github_repo` with branch-protection observations for `ORG/REPO` and a branch (default `main`).
