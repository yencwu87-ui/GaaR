# v0.8 Governance Decision Architecture

```text
Evidence + Requirement Elements
          |
       ClaimRegister
          |
   GroundingAssessment
          |
   +------+------+
   |             |
Challenge     Falsification
   |             |
   +------+------+
          |
 Context / lineage
          |
 Governance Decision Engine
          |
   +------+------+-------+
   |             |       |
adequate     remediate escalate/defer
          |
      Human decision
          |
      append-only event
```

The engine is a compiler, not a judge. It consumes governed records and emits a deterministic
posture, blockers, escalation signals, consistency measurements and a basis hash. The reviewer
can still choose the final action when no hard blocker exists.

## v0.8 policy

| Condition | Result |
|---|---|
| Contradicted claim + `full` | Block / defer |
| Failed falsification probe + `full` | Block / defer |
| Unresolved strong challenge + `full` | Block / defer |
| Recurring deficiency | Escalate |
| Longitudinal deterioration | Escalate |
| `partial` / `none` with no escalation | Remediate |
| `full` with no blockers | Adequate |

## Why this is the v0.8 boundary
v0.6 made claims/evidence/challenges governable objects. v0.7 made falsification bounded and
lineage-aware. v0.8 turns those objects into a deterministic governance decision projection while
keeping the final human decision explicit and auditable.
