## Outcome model
Global `OVS-*` outcomes aggregate governed MAS/MGF requirement-element decisions. Outcomes do not replace or override framework obligations.

Posture precedence:
1. `defer` — hard blocker
2. `escalate` — longitudinal/escalation signal
3. `remediate` — any mapped item below full or unresolved
4. `adequate` — all mapped items full

## Actual framework namespaces verified in-repo
- MAS: `M1.x`–`M4.x`, `F1`–`F4`
- MGF Agentic: `D1.x`–`D4.x`

The crosswalk uses actual IDs such as `MAS M3.12` and `MGF D2.2`; it does not introduce placeholder `MGF-*` IDs.
