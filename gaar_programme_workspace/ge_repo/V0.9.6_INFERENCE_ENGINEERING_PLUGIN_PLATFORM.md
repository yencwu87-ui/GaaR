# v0.9.6 — Inference Engineering + Governance Plugin/Tool Foundation

This build adds an inference-engineering control plane without turning model output into an
automatic governance decision.

## Inference layer

- `inference/policy.py` classifies work as routine/strong/critical from observable task signals.
- `inference/orchestrator.py` supports deterministic quality-gated escalation to a stronger model.
- `inference/telemetry.py` records task completion, calls, escalations, validation failures and latency.
- `assessor` element evaluation can now consume advisory verification metadata without changing the governed requirement.
- requirement-element drafting routes failed element-quality outputs through the inference quality gate.

## Plugin/tool foundation

- plugin metadata now declares capabilities and side-effect class.
- `tools/sdk.py` defines a ToolSpec/ToolResult contract and explicit `read_only`, `write`, `destructive` side-effect classes.
- `tools/registry.py` provides a registry seam without requiring remediation implementations.

## M3.6 element contract

M3.6 is now a 14-atom executable requirement contract. Elements were split by independently testable
obligation, while verification hints live separately in `governance/knowledge/element_testing.yaml`.
Those hints are advisory and cannot create requirements.

The M3.6 evaluation corpus has been structurally rebound to the 14 elements with `?` labels pending
human re-argument; old labels are not copied across element IDs.
