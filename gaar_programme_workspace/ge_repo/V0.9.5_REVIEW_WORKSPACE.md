# AI Governance Engine v0.9.5 — Review Workspace

## UX change
The previous Controls + Assess navigation has been collapsed into a single **Review** workspace.

The default reviewer flow is now:

Review Queue → one control → one step at a time → next step → decision → next pending control

### Main navigation
- Scan
- Review
- Report
- Outcomes
- Audit
- History
- Lifecycle

The old Controls tab and long Assess page are no longer primary navigation surfaces.

## Progressive review steps
1. Evidence
2. Your reading
3. AI assessment
4. Compare
5. Challenge
6. Decision
7. Complete

Completed work is represented by compact status/progress rather than remaining fully expanded on the page.

## Governance invariants preserved
- Blind human reading remains before AI proposal visibility.
- AI proposal is computed from evidence/control contract, not the reviewer reading.
- Comparison remains deterministic.
- Challenge remains questions-only and cannot become the recorded decision.
- Challenge responses continue through the append-only dossier/event paths.
- The decision engine remains the sole authoritative decision boundary.
- UI state remains a cache; governance state remains the event projection.

## Notes
The new Review workspace is implemented directly in `app.py` to minimize governance refactoring. The previous workflow logic was replaced by a compact, state-driven renderer using the existing `review_queue.py`, event projection, cycle API, challenge system, and decision engine.
