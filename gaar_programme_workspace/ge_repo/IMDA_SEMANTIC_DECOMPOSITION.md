# IMDA / MGF for Agentic AI — Semantic Decomposition

This increment replaces one-line, title-like requirement elements for the MGF Agentic controls with purposeful reviewer-facing elements grounded in the supplied July 2026 IMDA instrument.

## Scope

- Framework: `MGF Agentic`
- Controls: 34
- Element granularity: one meaningful obligation per element
- Verification: `HUMAN_JUDGEMENT` unless a deterministic predicate is separately justified
- Source matching remains `INSTRUMENT_MATCH_CANDIDATE`; it is not human source sign-off.

## D1.3 example

The former single element — “cap the agent's blast radius before build” — is now decomposed into:

1. minimum necessary tool/system scope
2. bounded autonomy
3. contained area of impact
4. deterministic enforcement / layered oversight

The UI now exposes the element text directly and provides an expanded element-detail view.
