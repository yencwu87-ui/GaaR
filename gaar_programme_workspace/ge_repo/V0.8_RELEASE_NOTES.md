# v0.8 — Governance Decision Engine

v0.8 completes the incremental governance path: **GROUND → FALSIFY → DECIDE**.

## Core rule
The model never owns the governance outcome. The human reviewer remains the decision authority;
the deterministic Governance Decision Engine compiles the governed record and blocks hard conflicts.

## Added
- `governance/decision_engine.py`
- deterministic decision posture: `adequate | remediate | escalate | defer`
- hard blockers for contradicted claims, failed falsification probes, and unresolved strong challenges
- longitudinal signals for recurring deficiencies and deterioration
- assessor/reviewer/final consistency projection
- decision basis hash for reproducibility
- governance evaluation persisted with the final `decided` event
- v0.8 regression tests

## Operational invariant
A `full` governance decision cannot be closed when the governed record still contains a material
contradiction, a failed falsification probe, or an unresolved strong challenge.

This is a deterministic enforcement layer; it does not claim to independently prove semantic
contradiction. That remains the responsibility of the governed Claim/Grounding assessment.
