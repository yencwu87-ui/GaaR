# v0.9.3.1 Hotfix

## Fix
Fixed a `NameError: name 'i' is not defined` in the challenger claim-vetting path when multiple verified evidence quotes are returned.

The buggy list comprehension referenced an undefined `i`. It now uses `enumerate()` with a stable local index.

## Regression coverage
Added `tests/test_challenge_claim_evidence_ids.py` to verify deterministic evidence IDs for multiple verified quotes.

## Governance impact
No governance semantics changed. The hotfix restores the existing Challenge Review path; it does not change evidence authority, blind-read ordering, challenge strength, decision admissibility, or web-knowledge treatment.
